PARKINSON'S SCREENING GAME — ASSET PACK
========================================

This package contains starter visual assets for a Pygame prototype.
All graphics are original generated/drawn starter assets and can be modified.

STYLE
- Dark navy medical-tech interface
- Blue/cyan primary highlights, purple test-selection highlights
- Green = neutral/positive UI state; amber = caution; red = seek professional advice
- Backgrounds: 1280 x 720 PNG
- Buttons/icons/reference drawings: transparent PNG where applicable

FOLDERS
backgrounds/  Scene backgrounds:
  menu_bg.png, selection_bg.png, loading_bg.png,
  drawing_bg.png, result_bg.png, instruction_bg.png

buttons/      UI button graphics:
  start.png, settings.png, about.png, exit.png,
  spiral_test.png, wave_test.png, start_game.png,
  submit.png, clear.png, back.png, retry.png,
  home.png, continue.png

icons/        Status and utility icons:
  normal.png, caution.png, consult.png, info.png, brain.png,
  sound_on.png, sound_off.png, help.png, settings_icon.png,
  home_icon.png, progress_bar_sample.png, loading_spinner.png

references/   Drawing prompts:
  spiral_reference.png, wave_reference.png

illustrations/ is reserved for additional character/medical illustrations.

IMPORTANT
- These are interface assets, not clinical evidence or diagnostic criteria.
- Do not label a player as having or not having Parkinson's based on this game.
- Display model output as an experimental screening indication only.
- A trained clinician must make any diagnosis.
- Check dataset licensing and permissions before redistributing dataset images.
